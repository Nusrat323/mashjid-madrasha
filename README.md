# পাইকপাড়া কাজীবাড়ী মসজিদ — ওয়েবসাইট

React + Tailwind CSS (v4) + Node/Express + MongoDB + Firebase Authentication দিয়ে তৈরি ফুল-স্ট্যাক ওয়েবসাইট।

## ফোল্ডার কাঠামো

```
client/   React (Vite) ফ্রন্টএন্ড
server/   Express API + MongoDB
```

## প্রয়োজনীয় জিনিস

- Node.js 20 বা তার উপরে
- MongoDB (লোকাল অথবা MongoDB Atlas)
- একটি Firebase প্রজেক্ট

## ১. Firebase সেটআপ

1. [Firebase Console](https://console.firebase.google.com) এ নতুন প্রজেক্ট খুলুন।
2. **Authentication → Sign-in method** থেকে **Email/Password** ও **Google** চালু করুন।
3. **Project settings → General → Your apps** থেকে একটি Web app যোগ করুন। যে কনফিগ পাবেন সেখান থেকে `apiKey`, `authDomain`, `projectId`, `appId` কপি করে `client/.env` এ বসান।
4. **Project settings → Service accounts → Generate new private key** চাপুন। ডাউনলোড হওয়া JSON ফাইল থেকে `project_id`, `client_email`, `private_key` নিয়ে `server/.env` এ বসান।
   `FIREBASE_PRIVATE_KEY` ডাবল কোটেশনের ভেতরে এক লাইনে রাখুন (যেমন `"-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"`)।

## ২. সার্ভার চালু করা

```bash
cd server
npm install
cp .env.example .env
npm run dev
```

`.env` ফাইলে `MONGODB_URI`, Firebase তথ্য এবং `ADMIN_EMAIL` দিন।
নমুনা নোটিশ ও অনুষ্ঠান চাইলে: `npm run seed`

## ৩. ফ্রন্টএন্ড চালু করা

```bash
cd client
npm install
cp .env.example .env
npm run dev
```

ওয়েবসাইট খুলবে `http://localhost:5173` এ।

## প্রথম অ্যাডমিন

`server/.env` এর `ADMIN_EMAIL` এ আপনার ইমেইল দিন। এরপর ওয়েবসাইটে ঐ ইমেইল দিয়ে **গুগল লগইন** করুন (অথবা ভেরিফায়েড ইমেইল ব্যবহার করুন)। প্রথমবার লগইনেই আপনি অ্যাডমিন হয়ে যাবেন এবং মেনুতে **অ্যাডমিন প্যানেল** দেখতে পাবেন। পরে অন্য কাউকে অ্যাডমিন বানাতে চাইলে অ্যাডমিন প্যানেলের **ব্যবহারকারী** পেজ থেকে করা যাবে।

## ব্যানার ছবি

মাদ্রাসার ছবি এই নামে রাখুন:

```
client/public/images/madrasha-banner.jpg
```

ছবি না থাকলে হোমপেজে সুন্দর নীল গ্রেডিয়েন্ট ব্যাকগ্রাউন্ড দেখানো হবে। কমপক্ষে 1920×1080 সাইজের ল্যান্ডস্কেপ ছবি ব্যবহার করুন।

## পেমেন্ট ব্যবস্থা

| মাধ্যম | কীভাবে কাজ করে |
| --- | --- |
| বিকাশ (অনলাইন গেটওয়ে) | `server/.env` এ bKash Tokenized Checkout এর `BKASH_*` তথ্য দিলে দাতা বিকাশ পেমেন্ট পেজে যাবেন, পেমেন্ট শেষে দান নিজে থেকেই "সম্পন্ন" হবে। |
| বিকাশ / নগদ (ম্যানুয়াল) | গেটওয়ে চালু না থাকলে দাতা মসজিদের নম্বরে টাকা পাঠিয়ে TrxID জমা দেন। অ্যাডমিন যাচাই করে অনুমোদন করেন। |
| ব্যাংক | দাতা ব্যাংকে জমা দিয়ে রেফারেন্স জমা দেন। অ্যাডমিন যাচাই করে অনুমোদন করেন। |

- বিকাশ নম্বর, নগদ নম্বর, ব্যাংক অ্যাকাউন্ট ও জামাতের সময় **অ্যাডমিন প্যানেল → সেটিংস** থেকে বদলানো যায়।
- bKash এর `BKASH_BASE_URL` ডিফল্টে sandbox দেওয়া আছে। লাইভ করতে bKash মার্চেন্ট অ্যাকাউন্টের production তথ্য ও `https://tokenized.pay.bka.sh/v1.2.0-beta` ব্যবহার করুন।
- নগদের অফিসিয়াল API-র জন্য মার্চেন্ট অনবোর্ডিং ও RSA কী লাগে, তাই এখানে নগদ ম্যানুয়াল যাচাইয়ে রাখা হয়েছে।

## অ্যাডমিন প্যানেলে যা যা আছে

- **ড্যাশবোর্ড**: মোট দান, এই মাসের দান, মাসভিত্তিক চার্ট, মাধ্যম ও উদ্দেশ্য অনুযায়ী হিসাব, সাম্প্রতিক দান
- **দানসমূহ**: কে কত টাকা কবে দিয়েছে (তারিখ, সময়, সাল), সার্চ ও ফিল্টার, অনুমোদন / বাতিল / মুছে ফেলা
- **ব্যবহারকারী**: সব নিবন্ধিত ব্যবহারকারী ও ভূমিকা পরিবর্তন
- **নোটিশ ও অনুষ্ঠান**: যোগ, সম্পাদনা, মুছে ফেলা
- **বার্তা**: যোগাযোগ ফর্মের বার্তা
- **সেটিংস**: যোগাযোগ, জামাতের সময়, পেমেন্ট তথ্য

## লেখা পরিবর্তন করতে চাইলে

কার্যক্রম ও মাদ্রাসার বিভাগের নমুনা লেখা আছে `client/src/data/site.js` ফাইলে। আপনাদের প্রকৃত তথ্য অনুযায়ী সেখানে বদলে নিন।

## ডিপ্লয়

- ফ্রন্টএন্ড: `cd client && npm run build` করে `dist` ফোল্ডার Netlify / Vercel এ দিন। Netlify এর জন্য `public/_redirects` ফাইল দেওয়া আছে।
- সার্ভার: Render / Railway / VPS এ চালান। `CLIENT_URL` ও `SERVER_URL` প্রোডাকশন ঠিকানা দিন।
- ফ্রন্টএন্ডের `VITE_API_URL` এ সার্ভারের ঠিকানা (`https://your-server.com/api`) দিন।
- Firebase Authentication → Settings → Authorized domains এ আপনার ডোমেইন যোগ করুন।
